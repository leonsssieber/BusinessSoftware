# Business Software Studio

Three subscription products built on one shared core:

| Product | What it does | Who pays |
|---|---|---|
| **QuoteRunner** | AI purchasing agent: one request to every supplier, quotes compared side by side, best award in minutes | Small contractors and machine shops |
| **DryDocs** | AI drying documentation for water-damage jobs: readings, equipment days, adjuster-ready reports | Small restoration companies |
| **AgentFit** | Tests whether AI coding agents can use your API, and shows how to fix the docs | API and developer-tool companies |

- Why these three: [docs/research/ideas.md](docs/research/ideas.md)
- How to run them as a portfolio: [docs/strategy/portfolio.md](docs/strategy/portfolio.md)
